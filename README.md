# Iris-ML-Algorithms
Collection of machine learning algorithms applied on the IRIS dataset for comparison and experimentation.

## ML Algorithms on the IRIS Dataset

This repository contains a consolidated notebook applying multiple machine learning algorithms on the classic IRIS dataset. The notebook is designed as a preparation and experimentation file to compare classification and clustering techniques.

## Algorithms Implemented

- ID3

- Random Forest

- KNN

- SVM

- K-Means Clustering

- Gaussian Mixture Model (GMM)

- PCA

- Self-Organizing Maps (SOM)

- Locally Linear Embedding (LLE)

- Find-S Algorithm

- Candidate Elimination Algorithm

- Factor Analysis

- Hierarchical Clustering

## Contents

- iris_algorithms.ipynb – Notebook containing all implementations

- iris.csv – Dataset
